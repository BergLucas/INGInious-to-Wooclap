# INGInious-to-Wooclap

INGInious-to-Wooclap is a small script to convert the questions of [INGInious](https://inginious.org/) to the format of [Wooclap](https://www.wooclap.com/).

- **Downloads page:** https://github.com/BergLucas/INGInious-to-Wooclap/releases

## Requirements

The application requires:

- [Python](https://www.python.org/) ~= 3.10
- [pip](https://pip.pypa.io/en/stable/)

## Download & Installation

There is only one way to download and install the application:

### Using Git

You can install the application using Git by running the following command:

```bash
pip install git+https://github.com/BergLucas/INGInious-to-Wooclap.git
```
